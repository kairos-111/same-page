# Same Page 使用说明（0.10.2）

**每一句，都跟得上。**

用本地 AI，把正在听的内容变成原文字幕与译文。支持**英语→中文、俄语→中文、英俄中混合→中文（试用）**。麦克风、电脑声音、导入文件每次选择一种。原文栏保留实际识别出的语言；纯中文直接同步到中文栏，外语直接译中文，不经过英文中转。

开发与交接以唯一 [PRD](PRD.md) 为准。识别和翻译可能出错、落后或漏词；品牌改名不代表这些问题已经解决。

## 打开应用

在项目文件夹“项目资料 → 01_本机应用”中，双击 **Same Page.app** 或 **打开 Same Page.command**。程序、Python、Small/Turbo/Hy-MT与采集组件已在本机应用中整合；打开不会自动录音。

旧“听课.app”和“打开听课.command”保留兼容入口。用户目录仍为 `~/Library/Application Support/听课/`，应用标识保持原值，以继续读取原来的记录和偏好。不要手动将旧开发版资料回迁：两套记录是独立副本，重新复制可能恢复你已删除的内容。

本机独立版使用8877/8878。开发网页入口为 http://127.0.0.1:8767/ ，用项目的“启动课堂翻译.command”；开发窗口可从项目根目录运行 `.venv/bin/python scripts/desktop.py`。不要同时在独立版和开发版启动模型。

## 选择识别模式

左侧“本地模型”上方选择“识别模式”：

- 英语→中文：固定英语转写，英文原文及中文译文。
- 俄语→中文：固定俄语转写，俄文原文及中文译文。
- 英俄中混合→中文：自动检测各语段语言，左侧保留原文；中文直接保留，英语/俄语直接译中文。允许一段内切换，混合模式目前为试用，请核对切换处。

模式与Small/Turbo模型分别选择；继续保留Small默认。记住上次模式，开始/翻译/保存期间锁定，结束后才能为下一次更改。首页显示当前模式，记录详情/历史和TXT也记录模式；旧记录默认按当时英语模式展示，不回写。

混合识别利用短静音分段，重用同一音频区间的结果，避免重复计算。同句没有明显停顿、很短的外语夹词、轻声/噪声/多人重叠仍可能误判。识别模型可能输出繁体字，本版通过本地字词转换统一为简体中文，不通过翻译模型改写。原文中的中文、译文、历史阅读和新下载的TXT/SRT均显示简体。英俄文保持原样，历史事件原件不回写。语言置信度低时会结合英俄中范围及相邻上下文继续判断；暂时异常最多等待2秒新音频，保留当前缓冲。仍未确认的区间只在“详情”里查看，正文不再显示提示卡片或系统消息。程序不回退至不限语言自动识别，也不会删符号冒充成功。发现原文错误时应结合保留录音核对，重译不能修复识别错误。

## 开始翻译与模型控制

1. 左侧“开始翻译”，选“麦克风”“电脑声音”或“导入文件”。麦克风使用macOS当前默认输入设备；电脑声音包含其他应用播放的声音，不能按应用筛选。
2. “记录名称”可不填，新建时默认为“新记录”；既有记录的标题不会改写。导入文件可选择或拖入音频/视频，最大1GB。本机应用0.10.1按原速读取；0.10.2起会尽快处理，顶部显示已识别的时长和百分比，中途结束只识别到当时位置，其余部分在详情中列为未处理。
3. 在“识别设置”里选择模型，默认快速Small，Turbo用于对照。也可在设置页保存下次使用的默认模型。
4. 点击“开始翻译”才会采集或读取音频。首次采集可能需要麦克风或屏幕与系统音频录制权限，按系统提示操作；程序不会自动替你授权。

左侧“本地模型”提供一键启动、停止全部和逐项启停。列表按Small、Turbo、Hy-MT翻译排序。右侧显示当前状态：未加载时为红色“已停止”，加载后为绿色“启动”。点击红色“已停止”会启动，点击绿色“启动”会停止；悬停可看操作提示。一键启动会加载三个模型，Small和Turbo权重可同时保留；实际翻译仍只用设置里选定的一个识别模型。停止一个不会卸载另一个；停止全部释放三个模型，不删除权重和记录。翻译、加载及收尾保存时，手动启停受保护。下次开始翻译会按需加载模型。

## 阅读字幕

原文和译文相邻显示，窄屏上下排列。连续几句会分段，原文逐字显示、修订平滑更新。历史与刷新快照直接完整显示，不重放动画。

- 顶栏“只看译文”切换显示；“原 −/+”“译 −/+”分别调整字号，阅读偏好自动保留，键盘+/−调整译文字号。
- 上翻后暂停自动跟随，点击“↓ 回到最新”返回。鼠标指向一句时原文与译文对应高亮。
- 原文已更新、译文未更新时保留旧译文并标注待更新，悬停可看版本。失败时可点“↻ 重新翻译”；重新翻译不能修复识别缺口。
- “详情”区分识别积压、当前/上次识别执行、翻译排队、执行及中文版本未跟上时长。版本落后计时不是音频延迟，不能与各阶段时长相加。

## 结束与录音选择

点击顶栏“结束”，按钮提示“确定结束？”后3秒内再点一次才结束，Esc可取消。等待识别/翻译收尾和落盘，保存后可以下载双语文本和SRT。

保存完成后弹出“保留本次录音吗？”，只有两个选项：

- **保留录音**：保留原声、字幕与历史。
- **不保留录音**：永久删除本次音频，保留字幕、修订和历史。

没有“稍后决定”，Esc不能跳过；正常退出也需完成当前记录的选择。旧历史不会自动弹出选择。音频一经删除不能再用于回听或补处理。导入时不会删除最初选取的原文件，只清理应用能确认归属、未被其他记录共用的上传副本。

若显示“已保存，有内容待核查”，可点击“详情”查看未识别的时间范围与核查信息，或查看TXT，结合保留的原声检查。“已保存”和“流程核对通过”不证明逐词完整或准确。点击“开始新的翻译”返回首页，前次记录继续保留。

## 我的记录

左侧“我的记录”可以按名称搜索。点击标题或“查看记录”，直接打开和翻译阶段一样的双语字幕界面，从开头完整显示。可调字号、只看译文、导出文本/SRT，点返回回到列表；不重新识别或翻译。

“查看录音 ↗”在访达选中第一段WAV，双击用系统播放器回听，其他分段在同一目录。异常结束可能定位PCM；未保留音频时会注明。

- **删除录音**：仅删除本次音频，记录、字幕和修订保留。
- **删除记录**：删除本次记录、字幕、事件、导出和全部分段录音。

两种删除均先显示应用内确认框，展示记录名与影响范围；默认焦点在取消，取消/Esc不提交。确认后永久删除，无法撤销。正在翻译或保存时不能执行删除；其他记录、模型与导入原件不受影响。

## 设置与退出

“设置”包含默认识别模型、默认只看译文、实际模型/记录文件目录与术语表入口，以及关于Same Page。原文/译文字号在字幕页调整。关于中的“产品介绍与支持范围”说明三种当前模式及混合试用边界。

关闭窗口或Cmd+Q先显示退出确认。选择“继续使用”不退出；有活动记录时确认退出会先结束保存并处理录音选择，然后关闭所有模型。应用只结束自己启动的后台，不任意停止共享服务。

## 术语、保存与恢复

在设置中打开术语目录，编辑实际文件 `outputs/课程术语.csv`（文件名保留兼容，不是“术语表.csv”）。`english,chinese`用于翻译匹配，也支持可选`source`或`russian`列中的源词；原CSV不重写。固定英/俄模式的识别提示按语言筛选，混合模式不注入跨语言历史/术语提示，术语仍用于翻译；可选第三列`asr_enabled`仅在相关词条填`true`、`1`或`yes`才注入识别提示，空白不启用。下次翻译生效，不需删除原词条。

独立版记录在 `~/Library/Application Support/听课/outputs/sessions/会话编号/`；开发版在项目`outputs/sessions/`。原声录制中按五分钟分段落盘（PCM）。本机应用0.10.1正常结束时为每段另存一份WAV，PCM与WAV都保留；0.10.2起合并为一个WAV并删除PCM，录音只占一份空间。原文和译文修订均有事件记录。

严重循环重复/异常时间戳会触发有限恢复。仍无法确认时，字幕与TXT保留缺口和区间，旧译文撤回，不将异常段定稿或加入SRT。VAD前置音频和有限覆盖恢复减少边界风险，但不能保证识别全部声音。

结束核对未读音频、识别收尾、缺口与全量字幕版本。TXT分别标注原文与译文状态；SRT只含原文定稿、译文非空且版本匹配的句子，不能单靠SRT判断完整性。旧导出原件保留，新生成核对下载可能带“核对版”后缀。

异常退出后，已收到的原声与事件尽量保留。开发者可从对应项目/数据环境用`scripts/recover_session.py`重建文字与WAV，再导入补处理；缺失声音不能补回。不要在不核对数据根目录时对当前独立版运行旧开发版恢复命令。

## 离线与验证边界

模型及资源就绪后，核心听译与保存不依赖云端，不调用云端翻译API或上传录音。外部视频自身的播放仍取决于来源。Small在已有本机短样例上更及时，不能据此推断所有课堂更准。

0.9.0更新范围是品牌和文案；必要管理/API/前端回归及本机窗口检查详见PRD和本轮验证记录，没有本轮麦克风录音、真实模型提速对照或90分钟长测。安装包、公证和对外分发继续暂停。

0.9.1更新模型控制：三个模型可一键加载，预加载不开始录音，也不表示两个识别模型会同时识别。新会话仍会初始化自己的VAD和上下文，首次识别时仍可能有初始化耗时。

本轮已在本机独立版验证：三个模型同时加载、仅停止Small保留Turbo和翻译、全部停止及按钮配色/顺序；73项Python及5项前端专项通过。未录音，未进行翻译速度或准确率对照，历史记录未改。

## 0.10.2 更新

- 录音只存一份：结束时合并为一个WAV文件。以前的记录仍有重复的PCM，可由开发者运行 `scripts/dedupe_recordings.py` 先预览可释放空间，确认后加 `--apply` 删除与WAV内容完全相同的PCM；不会动正在进行或未结束的记录。
- 应用内回听可以完整播放和拖动进度，超过5分钟的旧记录也合成一条播放；打开另一条记录时会停止并换成该记录的录音。
- 导入文件不再按原速处理，进度显示在顶部。
- 界面第一步改版：
  - 开始页：在声音来源下面直接选“识别语言”（英语、俄语、英俄中混合），开始按钮旁的下拉选“标准 · Small”或“更准 · Turbo”；按 ⌘↵ 也能开始，输入记录名称时同样可用。
  - 左侧只显示模型状态（如“2/3 运行中”或“未加载”），点它进入设置页。一键启动、全部停止和逐个启停都在设置页“本地模型”，状态显示为“运行中 / 已停止”。打开应用时会自动加载全部模型（不会自动录音），退出时自动关闭；中途仍可在设置页手动启停。开始翻译时如模型未加载，也会自动加载所需模型。
  - 字幕页顶栏只有：延迟标签、显示、导出、结束。延迟标签写“已跟上 / 延迟约 N 秒 / 落后 N 秒”，导入文件时写处理百分比，结束后写“详情”或“待核查 N 处”；点开就是原来的详情。复制全部字幕和三种下载都在“导出”里。
- 这些改动只做了受控测试，未用真实长文件、模型或麦克风验证。

## 运行数据与累计数据（PRD 2.4.0）

- 左侧“运行数据”：看字幕跟得多快、哪里卡过。顶部是出字延迟的中位数（说完一句到出现中文）和分布，右侧是定稿延迟、识别落后峰值和待核查区间；下面是每次记录的趋势和记录列表。点一条记录进入诊断页：整场时间线、时间花在哪个环节、异常事件列表（点一条直接跳到那句字幕），以及运行日志的导出和摘要复制。数字只计处理时间，不代表识别或翻译是否准确；较早的记录没有分阶段计时。
- “我的记录”顶部：累计听了多久（按语言分开）、记录数、字幕句数、译文字数，以及近 14 天的使用格子和连续天数。删除或恢复记录后会自动更新；废纸篓里的记录不计入。
- 应用图标改为“声波成字”：深绿底，左边声波，右边三行字幕。

## 0.10.0 验证边界

本轮用本地合成语音检验固定英/俄转写、纯中文、同句混合及三语轮流；独立文件导入到保存/导出的四组短测均完成，中文样本未进入翻译队列。Small在本轮混合短样本上更合适，不能外推所有场景；没有真实课堂、长时延迟或口音覆盖验收。不自动录音、不上传，安装包继续暂停。

0.10.0提供三种面向中文的模式（混合为试用），本次修复异常语言回退和符号循环。87项受控检查及4组合成文件流程通过；不证明现场识别准确，也不承诺固定延迟。不保留录音后，该次原声无法补处理。

0.10.1修复短片段语言误拒与立即清缓冲。用户授权37秒原声对照由旧4个未确认区间降为0个；这不证明逐词准确，混合仍需核对。
