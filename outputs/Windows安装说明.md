# Same Page Windows 版 · 安装说明

安装包：`SamePage-0.10.2-windows-x64-setup.exe`（约 1.8 GB，附 `.sha256` 校验值）

## 电脑要求

- Windows 10（64 位，2021 年以后的更新）或 Windows 11
- 2014 年以后的 Intel / AMD 处理器（需要支持 AVX2，近十年的电脑基本都支持）
- 内存 8 GB 起，推荐 16 GB
- 约 2.5 GB 可用磁盘空间
- 已装 Microsoft Edge（Windows 自带）
- 不需要管理员权限，不需要联网，也不需要账号

## 安装

1. 双击 `SamePage-0.10.2-windows-x64-setup.exe`。
2. 如果出现蓝色的“Windows 已保护你的电脑”：点**更多信息 → 仍要运行**。安装包没有购买微软签名，所以会出现这个提示；有的杀毒软件也可能拦截，选“允许”即可。
3. 按提示点“下一步”，默认装到 `C:\Users\你的用户名\AppData\Local\Programs\Same Page`。
4. 装好后勾选“现在打开 Same Page”，或者双击桌面上的 **Same Page** 图标。

## 第一次打开

- 先出现一个“正在启动本地引擎…”的小窗口，第一次可能要等半分钟，之后会打开 Same Page 窗口。
- 窗口打开后会在后台加载识别和翻译模型，侧栏左下的模型状态显示“2/2 运行中”就好了。
- **麦克风：** 如果开始后没有字幕，打开 Windows“设置 → 隐私和安全性 → 麦克风”，把“麦克风访问”和“允许桌面应用访问麦克风”都打开。
- **电脑声音：** 选“电脑声音”会录下默认扬声器或耳机正在播放的声音（比如网课、视频），不需要额外授权。

## 和 Mac 版的区别

- 识别用 CPU 运行（Small 模型），出字会比 Mac 慢一些，电脑越新越快。没有 Turbo 模型。
- 翻译优先用显卡（Vulkan），没有可用显卡时自动改用 CPU。
- 关闭窗口就会退出：如果正在翻译，会先弹出“确定离开吗”的提示；确定后会先保存本次记录，再关闭模型。
- 窗口由系统自带的 Edge 以应用模式打开，任务栏图标和 Edge 在一起是正常的。

## 记录和日志存在哪里

- 记录、录音和设置都在 `%LOCALAPPDATA%\Same Page`，和程序分开放，重装或升级不会丢。
- 出问题时，把 `%LOCALAPPDATA%\Same Page\work` 里的 `launcher.log`、`desktop-engine.log`、`llama-server.log` 发给我。
  （在资源管理器地址栏粘贴 `%LOCALAPPDATA%\Same Page\work` 回车即可打开。）

## 卸载

“设置 → 应用 → 已安装的应用”里找到 **Same Page** → 卸载。卸载时会问是否同时删除记录和录音，默认保留。

## 已知限制

- 这个安装包是在 Mac 上构建的，在模拟的 Windows 环境（Wine）里测过识别、翻译和保存，**还没有在真实的 Windows 电脑上测过**。第一次在 Windows 上用时，如果遇到问题，请把上面的日志发给我。
- 麦克风和电脑声音的录制只能在真机上验证。
